# Contributing

Viral Sync is a devnet/prototype repository. Contributions should keep that scope clear.

## Good contributions

- Local validator test improvements
- Documentation fixes
- Devnet setup improvements
- Relayer safety checks
- Clear bug reproductions

## Local setup

```bash
npm install
npm run verify
```

You also need the Solana and Anchor toolchains for protocol work.

## Pull requests

- Keep PRs focused.
- Include test results.
- Do not commit private keys, wallet files, RPC secrets, or real merchant/customer data.
- Do not remove devnet/mainnet safety warnings.
