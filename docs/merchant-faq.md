# Merchant FAQ

## What does the merchant pay?

During the pilot, platform billing stays paused. The merchant only funds the reward it chooses to honor.

## How do we know a referral caused a visit?

The app records a referral claim, a one-time counter challenge, dual attestation, and a Causal Receipt after staff confirms the customer is physically present.

## What if a customer sends the same code twice?

The code can be confirmed once. Replays are treated as already consumed or invalid depending on the state.

## What if staff makes a mistake?

Use the support console to search the code or claim. Managers can void unconfirmed codes from the merchant flow when needed.

## Can we run multiple branches?

Not for the first pilot. The Day 71-80 plan keeps one location active so training and fraud review stay clean.
