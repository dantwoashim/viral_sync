# Day 139 Incident Runbooks

## Failed Redemption

Search code in support console, then void unconfirmed code or retry confirmation.

## Failed Transaction

Check relayer monitoring and reconciliation, pause sponsorship, then rerun indexer.

## Fraud Spike

Review fraud dashboard and partner holds, then pause the partner source if needed.

## DB Issue

Switch to maintenance mode, snapshot ledger, restore backup or rollback migration.
