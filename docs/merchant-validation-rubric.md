# Merchant Validation Rubric

A merchant validation item is useful only if it includes at least one of:

- merchant quote with permission
- live demo completion
- concrete objection
- payout-size signal
- follow-up interest
- screenshot/video/photo with permission

Scoring:

- 0: invented or generic claim
- 1: informal conversation, no proof
- 2: quote or objection captured
- 3: merchant completed demo flow
- 4: merchant completed demo + gave follow-up signal
- 5: merchant completed demo + allowed public quote/media
